The Problem
LLMs Have a Memory Limit
Large Language Models can only read a fixed amount of text at once. This is called the Context Window.
🧠

Context Window

Models like GPT-4 can only process 8K–128K tokens at a time. Your document might be 500K+ tokens.

🕳️

Lost in the Middle

Even if text fits, LLMs lose track of information buried in the middle of long documents.

💸

Wasted Cost

Sending unnecessary tokens to the API wastes money. Processing only relevant chunks saves cost.

🤖

Hallucinations

When overwhelmed with irrelevant text, models make up answers — they "hallucinate" incorrect facts.

✂️  Solution: Intelligent Text Splitting

We believe that the most powerful and differentiated applications will not only call out to a language model via an API, but will also be data-aware: connect a language model to other sources of data. Be agentic: allow a language model to interact with its environment. The LangChain framework is designed with the objective in mind to enable those types of applications.
